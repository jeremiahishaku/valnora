# Razorbill by Valnora

Official responsive website and platform for Razorbill by Valnora.

## Overview

Razorbill is a modern web experience designed for consumers, businesses, and professionals. The product offers streamlined navigation, clear conversion paths, and a polished digital presence.

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS

## Getting Started

### Prerequisites

- Node.js 18+
- npm or Bun

### Installation

```bash
git clone https://github.com/jeremiahishaku/valnora.git
cd valnora
npm install
```

### Run locally

```bash
npm run dev
```

Then open http://localhost:5173

## Available Scripts

```bash
npm run dev
npm run build
npm run preview
```

## Main Routes

- `/` — Home
- `/about` — About
- `/our-app` — Our app
- `/for-businesses` — For businesses
- `/for-professionals` — For professionals
- `/blog` — Blog and updates
- `/contact` — Contact
- `/login` — Login
- `/get-started` — Get started
- `/signup/consumer` — Consumer signup
- `/signup/business` — Business signup
- `/signup/professional` — Professional signup
